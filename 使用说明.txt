护眼助手 使用说明
================

一、如何安装（无需电脑、无需开发环境）
---------------------------------------
1. 把本目录里的「eyeguard-release.apk」传到安卓手机上
   （用微信文件传输、USB 数据线、网盘等方式都可以）。
2. 在手机上点击这个 apk 文件。
3. 如果手机提示“禁止安装未知来源应用”：
   - 按提示点“设置”，打开“允许安装未知应用 / 未知来源”开关，然后返回继续安装。
   （这是安卓的正常安全提示，本软件不含任何广告、付费或联网功能。）
4. 安装完成后，在桌面找到“护眼助手”图标，点击打开即可。

二、第一次打开必须授予的权限（很重要）
-----------------------------------------
打开软件后：
1. 通知权限：会弹窗请求“通知”，请“允许”。
   软件在后台计时时需要在通知栏显示一个常驻通知，否则系统可能把后台服务杀掉。
2. 悬浮窗权限（显示在其他应用上层）：
   当你第一次点主界面的「开始」时，软件会引导你授予“悬浮窗”权限，请“允许”。
   休息提醒正是用“全屏悬浮窗”弹出的，如果不给这个权限，到点就弹不出全屏提醒。
   （如果当时没给，之后可在 手机设置 → 应用设置 → 护眼助手 → 权限管理 里补开。）
3. 电池优化 / 不受电池优化限制：
   点「开始」后软件会自动询问是否允许“忽略电池优化”，请选择“允许”。
   目的：防止手机在灭屏后把计时服务关掉，导致计时不准确。

三、主界面与按钮
-----------------
打开软件后，主界面显示三行时间：
- 本次已亮屏时间：从最近一次亮屏开始、到现在的连续亮屏时长（灭屏会清零并累计到下面那行）。
- 累计亮屏时间：所有亮屏时长加在一起的总和（一直保存）。
- 眼睛休息时间：累计你已经“休息眼睛”的总时长。

四个按钮：
- 开始：开始护眼计时（之后即使你切到别的 App、锁屏再亮屏，只要亮屏就在计时）。
- 暂停：暂停计时（保留已累计数据，下次点开始继续）。
- 退出：彻底停止计时、关闭后台服务、完全退出程序。
- 设置：进入设置界面，自定义外观和提醒规则（见下）。

四、设置界面能改什么
-------------------
- 主界面字体大小 / 字体颜色。
- 全屏弹窗（休息提醒）的背景颜色、文字内容、文字颜色、文字大小。
- 休息提醒间隔（分钟）：默认 20 分钟，到点全屏提醒。可在 1～N 分钟间自定义，精确到分钟。
- 眼睛休息时长（分钟）：默认 1 分钟，点“确认休息”后倒计时，结束自动关闭弹窗。可自定义。
- 开机自启动：开启后，手机重启会自动恢复“正在计时”的状态（见第六条注意事项）。

五、休息提醒是怎么工作的
-----------------------
1. 点“开始”后开始计时；每连续亮屏满“休息提醒间隔”分钟，会弹出一个全屏提醒。
2. 提醒上有一个「确认休息」按钮：
   - 点它 → 进入“眼睛休息倒计时”（时长=设置里的休息时长），倒计时结束自动关闭弹窗，
     这段休息时长会被记到“眼睛休息时间”里。
   - 如果不点 → 弹窗会在 2 分钟后自动关闭（这段不计入眼睛休息时间）。
3. 关闭弹窗后，下一次提醒会从 0 重新开始计算满一个间隔再提醒。

六、关于“息屏不计时、累计亮屏、自启动”的说明
---------------------------------------------
- 只有屏幕亮着才计时；屏幕熄灭时暂停，并把这一段亮屏时长并入“累计亮屏时间”。
- 每次重新亮屏，都会重新从 0 计算“本次已亮屏时间”（即单次亮屏独立记录）。
- 自启动：安卓本身禁止 App 自己偷偷开机启动。本软件已加入“开机自启动”能力
  （接收开机广播 + 设置里的开关）。但部分国产手机（华为/小米/OPPO/vivo 等）还要求你
  在系统的“自启动管理 / 应用启动管理 / 电池优化”里手动允许本软件“自启动/后台运行”。
  设置界面里的「打开系统自启动/电池设置」按钮会直接帮你跳到对应系统页面，按要求打开即可。

七、耗电与后台
-------------
- 软件仅在亮屏时每秒轻量计时、灭屏即停，并申请了“忽略电池优化”，对电量影响很小。
- 计时期间通知栏会显示一个“护眼助手运行中”的常驻通知，这是安卓要求的前台服务提示，属正常现象。

八、完全退出
-----------
点主界面的「退出」会停止所有计时、移除可能存在的提醒弹窗、关闭后台服务并完全退出。
（如果不点“退出”而直接划掉 App，后台计时服务仍会在通知栏继续运行，这是设计如此，
方便你离开软件也能继续护眼计时。）

九、红米 / 澎湃 OS 3 特别注意事项（重要）
----------------------------------------
小米/红米系统对后台应用限制很严，请务必做以下设置，否则可能“打不开”或“灭屏后不计时”：
1. 自启动：设置 → 应用设置 → 授权管理 → 自启动管理 → 找到“护眼助手”→ 打开允许自启动。
2. 后台运行/省电策略：设置 → 应用设置 → 护眼助手 → 省电策略 → 选“无限制”；
   或在“应用详情 → 其他权限/权限管理”里把“后台弹出界面”“显示悬浮窗”都打开。
3. 锁屏后台：设置 → 省电与电池 → 应用智能省电 → 护眼助手 → 设为“无限制”。
4. 如果装好后一点图标就闪退/闪一下消失：
   - 本软件已内置“崩溃自诊断”：若仍出错，会自动弹出一个全屏错误页，
     上面有完整错误信息。请点错误页里的「复制」或「分享」，把文字发给我，
     我就能精确定位并修好。
   - 也可以把错误页截图发我。
   -（若连错误页都不弹、直接回桌面，多半是系统“未知来源/安全扫描”拦截，
     请到 设置 → 应用设置 → 护眼助手 确认已“允许安装/启用”，并关闭“安全守护”对该应用的拦截。）

================
如安装或弹窗提醒有任何问题，请确认“悬浮窗权限”“通知权限”和“电池无限制”均已授予，
并在小米/红米系统中允许本应用“自启动 / 后台无限制”。
